`main.ts` (Node 22, stdlib only) writes a single one-star review of planet Earth, in the voice of an alien tourist who still slips in a real compliment about the food — 193 characters, 34 words — to `/output/entry.txt`:

> One star: your planet serves dinner on breakable discs, charges money for bottled rain, and locals argue about fruit on pizza — but one stick of satay made my three stomachs file for residency.

Run it with:

